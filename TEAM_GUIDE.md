# Team Collaboration Guide

## Team Size

5 students.

You are building ONE Campus Navigator.

Do not create five separate solutions.

## Defined Responsibility Areas

We have structured the codebase so each of the 5 students owns exactly one file to start:

1. **Student 1**: Campus location data (`src/locations.py`)
2. **Student 2**: Route/map graph data (`src/routes.py`)
3. **Student 3**: Navigation logic (`src/navigator.py`)
4. **Student 4**: Output and display formatting (`src/display.py`)
5. **Student 5**: Main application and validation (`src/main.py`)

While you each have ownership of a specific file to write, everyone must collaborate to ensure the final application connects and works.

Everyone should understand the complete project.

## Collaboration Rule

Understand -> Implement -> Test -> Explain -> Commit

## Before Asking a Mentor

Use:

Problem:
What is not working?

What I tried:
What did I attempt?

Evidence:
What output/error did I get?

Question:
What exactly do I need help with?

## Good Commit Messages

- Add campus locations
- Add campus route data
- Implement route search
- Calculate route distance
- Handle invalid locations
- Improve route display

Avoid:
- final
- changes
- updated
- new

# DEV MODE — SVECW Campus Navigator

## Problem Statement

Build a simple command-line application that helps a student find a route between two locations on the Shri Vishnu Engineering College for Women campus.

The campus is represented as a network of locations connected by paths. Each path has a distance.

The application should allow a user to:

1. View available campus locations.
2. Select a source location.
3. Select a destination location.
4. Find a route between them.
5. Calculate the total distance.
6. Display the route clearly.
7. Handle invalid locations.
8. Handle locations for which no route is available.

### Example

Input:

Source: Main Gate
Destination: Library

Expected:

Shortest route:
Main Gate -> CSE Block -> Library

Total distance: 300 m

## Important

This is a STARTER PROJECT designed for a team of 5 students.

The logic in all files is intentionally incomplete and heavily relies on `# TODO` comments. Read the `TASKS.md` file for exact role assignments before writing any code.

Do not assume that the first route you find is the shortest route.

The exact campus map used in this exercise is a simplified teaching model. It is not intended to represent exact physical distances or an official campus map.
